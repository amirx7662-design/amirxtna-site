شرح تفصيلي من الصفر المطلق حتى احتراف التطوير وتصميم المشاريع مع تدريبات عملية

🐍 مسار تعلم Python من الصفر حتى الاحتراف

المستوى 1: من الصفر (المتغيرات وأنواع البيانات)

المتغير هو مكان في الذاكرة لتخزين البيانات (أرقام، نصوص، أو قيم منطقية):

name = "Amir"
age = 12
is_developer = True
print("مرحباً يا", name)
🎯 تدريب رقم 1:

قم بإنشاء متغير يحمل اسم مدرستك ومتغير آخر يحمل صفك الدراسي، ثم اطبع جملة تجمع بينهما باستخدام print().

المستوى 2: الشروط والتحكم بالحساب (if / elif / else)

اتخاذ القرارات البرمجية بناءً على الشروط:

score = 85
if score >= 90:
    print("ممتاز 🌟")
elif score >= 50:
    print("ناجح ✅")
else:
    print("راسب ❌")
🎯 تدريب رقم 2:

اكتب برنامجاً يفحص درجة حرارة الطقس: إذا كانت أكبر من 30 يطبع "الجو حار"، وإذا كانت أقل يطبع "الجو لطيف".

المستوى 3: الاحتراف والتطوير (الدوال والسيرفرات)

تجميع الكود في دالة وإعادة استخدامه، ثم بناء سيرفرات الويب بـ Flask:

def check_pass(password):
    if len(password) > 8:
        return "كلمة مرور قوية"
    return "ضعيفة"

print(check_pass("Amir12345"))
🔥 التحدي الختامي لبايثون:

قم ببرمجة دالة حاسبة تأخذ رقمين والعملية (+ أو -) وترجع الناتج الصحيح للمستخدم.

🌐 مسار تصميم المواقع (HTML & CSS)

المستوى 1: هيكلة الصفحات (HTML)

بناء العناصر الأساسية مثل العناوين والأزرار والروابط:

<h1>أهلاً بكم في موقعي</h1>
<p>هذا أول موقع أقوم بتصميمه.</p>
<button>اضغط هنا</button>
🎯 تدريب رقم 1:

أنشئ صفحة فيها عنوان باسمك، وتحته زر ينقل الزائر إلى موقع جوجل <a href="...">.

المستوى 2: التنسيق والتصميم (CSS)

إضافة الألوان والخلفيات والمؤثرات الضوئية (النيون):

button {
    background-color: #00f2fe;
    color: #000;
    border-radius: 8px;
    box-shadow: 0 0 10px #00f2fe;
}
🎯 تدريب رقم 2:

قم بتغيير لون خلفية الصفحة إلى الأسود #000 مع جعل لون جميع النصوص أخضر نيون #00ff00.

⚡ مسار C++ للأنظمة والألعاب

المستوى 1: الهيكل الأساسي والمخرجات

أول برنامج بلغة C++ لعرض النصوص على الشاشة السوداء:

#include <iostream>
using namespace std;

int main() {
    cout << "Hello C++ World!" << endl;
    return 0;
}
🎯 تدريب رقم 1:

اكتب برنامجاً يستقبل عمر المستخدم باستخدام cin ويطبع له سنة ميلاده على الشاشة.
